# Diffusion-learn

拡散モデル（Diffusion Model）の仕組みを学ぶためのWebページです。単一のHTMLファイルだけで動作し、**ブラウザの中で本物の機械学習（ニューラルネットワーク）を実行**して、0〜9の数字を学習・生成します。

高校生を対象としており、数式を使わずに「ノイズを足す → ノイズを消す」という考え方を体験しながら学べます。

## 公開ページ

- GitHub Pages: https://mooman0222.github.io/Diffusion-learn/

## できること

1. **お手本データ** — 0〜9の数字を20x20のドットグリッド（MNIST風）で表示。学習させる数字を選べます
2. **ノイズを加える（拡散）** — スライダーでノイズの量を変え、形が崩れていく様子を観察
3. **直し方を学習** — ブラウザ内のニューラルネットワークが「ノイズを当てる練習」を繰り返し、誤差グラフと学習の進行をリアルタイム表示
4. **ノイズから生成** — 真っさらなノイズから数字が浮かび上がる生成アニメーション。毎回ランダムなので結果が変わります

## 使い方

ブラウザで `index.html` を開くだけです。インターネット接続やサーバーは不要です（学習はすべてブラウザ内で実行）。

```bash
# ローカルで確認する場合
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 技術メモ

- 単一HTML・外部依存なし（CDN不使用、オフラインで動作）
- ニューラルネットワーク: 入力(x, y, ノイズ量) → かくれた層48個×2 → 出力(ノイズ予測) を純JSで実装
- 最適化: Adam（学習率0.008）
- ノイズスケジュール: 三次曲線（ノイズ量が少ない領域を細かく学習）
- 数字データ: 7セグメント表示風の数字を20x20グリッドにラスタライズし、各セルを点群で表現
